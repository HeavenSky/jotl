# Manual acceptance

**English** · [简体中文](../zh/docs/acceptance.md)

Walk through this checklist in a real browser to confirm the Playground's layout, styling and interactions before a release; the unit tests run in jsdom, which computes neither layout nor styles. You need the dev server or `preview` running, as described in [Run it locally](../README.md#run-it-locally).

Set the UI language to English in the header first. The labels below are the English UI text; field titles such as 联系方式 come from the Chinese `v1-showcase` source and stay as they are. Perform the steps in order:

| Action                                                                                                                               | Expected                                                                                                                                                                                                                                                                           |
| ------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Open the page for the first time (or reload after clearing the `jotl-playground:source` key in `localStorage`)                       | The editor shows the `v1-showcase` source, each line number aligned with its source line; the right side opens on "Form preview", "联系方式" (Contact) is expanded within the root page, and "搜索优化" (SEO), "轮播图" (Banners) and others appear as entry rows                  |
| Click the "搜索优化" entry row, then click "店铺" (Shop) in the breadcrumb                                                           | The subpage opens with a breadcrumb at the top; clicking the breadcrumb returns to the root page                                                                                                                                                                                   |
| In the editor change `name(店名)` to `name(全名)` and stop typing                                                                    | The status bar briefly shows "Waiting to compile…" and then clears; the field label in the form becomes "全名"                                                                                                                                                                     |
| Type a shop name into the form                                                                                                       | "Current form data" shows the value as you type                                                                                                                                                                                                                                    |
| Move the cursor or use the arrow keys                                                                                                | "Ln X, Col Y" below the editor follows the cursor                                                                                                                                                                                                                                  |
| Misspell a type name (e.g. change `string` to `strng`)                                                                               | An error appears in the diagnostics list and its line number turns red; a yellow "Stale" notice appears at the top right, and the preview keeps the previous result, dimmed                                                                                                        |
| With a long source, scroll to the bottom and then click that diagnostic                                                              | The editor scrolls to the error line, selects the offending word, and the status bar shows the line and column from the diagnostic                                                                                                                                                 |
| Fix the error                                                                                                                        | The diagnostics list shows "No diagnostics" and the "Stale" notice disappears                                                                                                                                                                                                      |
| Switch through the "JSON Schema", "TS output" and "Degrade debug" tabs, then move between tabs with the arrow keys, `Home` and `End` | The tabs show the formatted schema, the TS declarations starting with the generated header, and each node's widget, source and fallback records                                                                                                                                    |
| At the top of the form preview switch "Layout" to "Collapsible panels"                                                               | Entry rows become collapsible panels whose header shows the title and summary, with the first level expanded; after you add an item to "轮播图", its panel title is "Item 1" plus a summary and the item can be duplicated; switching back to "Drill-down" restores the entry rows |
| Switch "Initial data" to "Mock"                                                                                                      | The form remounts and "Current form data" is replaced with randomly generated data                                                                                                                                                                                                 |
| In "Logo" click "Upload image" and pick a local image                                                                                | "Uploading…" shows briefly, then the URL box receives a `blob:` address and shows a preview (no network request)                                                                                                                                                                   |
| Open the "正文" (Body) field of a text block                                                                                         | The rich-text area has a formatting toolbar; selecting text and clicking bold, italic, link or list takes effect, and "Current form data" contains HTML                                                                                                                            |
| Select `013-x-ui-basic` in the example dropdown                                                                                      | The source is replaced with that example and compiled immediately; "Degrade debug" shows fallback records for unregistered widgets such as `headline`                                                                                                                              |
| Select `016-errors`                                                                                                                  | The diagnostics list shows all errors; the right side keeps the previous example's result marked "Stale"                                                                                                                                                                           |
| Edit anything and then reload the page                                                                                               | The editor restores the source from before the reload                                                                                                                                                                                                                              |
| Edit in a private window or with site storage disabled                                                                               | A "Local storage is blocked; the source will not be restored after reload." notice appears at the top; editing and preview work as usual                                                                                                                                           |
| Make the window narrower than 900px                                                                                                  | The editor and output areas stack vertically with no horizontal overflow                                                                                                                                                                                                           |
