# 人工验收

[English](../../docs/acceptance.md) · **简体中文**

发布前按本清单在真实浏览器中逐项操作，确认 Playground 的布局、样式与交互正常；单测运行在 jsdom 中，不计算布局与样式。前提是已按[在本地运行](../README.md#在本地运行)启动开发服务器或 `preview`。

先在页头把界面语言切到中文，下表中的界面文案以中文界面为准。按顺序操作：

| 操作 | 预期 |
|---|---|
| 首次打开页面（或清除 `localStorage` 的 `jotl-playground:source` 键后刷新） | 左侧编辑器是 `v1-showcase` 的源码，行号与源码行逐行对齐；右侧默认在「表单预览」，「联系方式」在根页内展开，「搜索优化」「轮播图」等显示为入口行 |
| 点击「搜索优化」入口行，再点面包屑中的「店铺」 | 进入子页，顶部出现面包屑；点面包屑退回根页 |
| 在编辑器中把 `name(店名)` 改成 `name(全名)`，停止输入 | 状态栏短暂出现「等待编译…」后消失；表单中的字段标签变为「全名」 |
| 在表单中输入店名 | 「当前表单数据」实时显示输入的值 |
| 移动光标或用方向键 | 编辑器下方的「行 X, 列 Y」随之变化 |
| 把某个类型名改错（如 `string` 改成 `strng`） | 诊断列表出现错误，对应行号变红；右侧顶部出现黄色「已过期」提示，预览保持修改前的结果且整体变淡 |
| 源码很长时滚动到底部，再点击该诊断 | 编辑器滚动到出错行并选中出错的词，状态栏显示诊断给出的行列 |
| 修正错误 | 诊断列表显示「没有诊断」，「已过期」提示消失 |
| 依次切换「JSON Schema」「TS 输出」「降级调试」页签，再用方向键、`Home`、`End` 在页签间移动 | 分别显示格式化的 schema、以生成头开始的 TS 声明，以及每个节点的 widget、来源与降级记录 |
| 在表单预览顶部把「呈现」切到「折叠面板」 | 入口行变为可折叠面板，标题行显示标题与摘要，第一层展开；「轮播图」新增一项后，该项面板标题为「第 1 项」加摘要，可复制；切回「钻取」恢复入口行 |
| 把「初始数据」切到「Mock」 | 表单重新挂载，「当前表单数据」换成随机生成的数据 |
| 在「Logo」点「上传图片」，选一张本地图片 | 短暂显示「上传中…」，之后 URL 框写入 `blob:` 地址并显示预览（不发网络请求） |
| 进入某个文本区块的「正文」 | 富文本编辑区带格式工具栏，选中文字后点粗体、斜体、链接、列表均生效，「当前表单数据」中为 HTML |
| 在示例下拉中选择 `013-x-ui-basic` | 源码替换为该示例并立即编译；「降级调试」中 `headline` 等未注册 widget 有降级记录 |
| 选择 `016-errors` | 诊断列表列出全部错误，右侧保留上一个示例的结果并标注「已过期」 |
| 编辑任意内容后刷新页面 | 编辑器恢复刷新前的源码 |
| 在浏览器隐私模式或禁用站点存储后编辑 | 顶部出现「浏览器禁止本地存储, 刷新后不会恢复源码.」提示，编辑与预览照常 |
| 把窗口宽度缩到 900px 以下 | 编辑区与输出区改为上下排列，没有横向溢出 |
