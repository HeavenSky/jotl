# 更新日志

[English](../CHANGELOG.md) · **简体中文**

## [0.0.5] - 2026-11-27

- 校验 `x-enumFrom` 时按原始类型匹配当前清单中的值；带标签的选项按 `value` 匹配。失效的单选值或多选元素会在对应的数据路径报告 `JOTL4006`。[枚举校验](../../../zh/docs/spec/jotl.md#枚举)

## [0.0.4] - 2026-11-06

### 修复

- 数据迁移选择联合分支时保留公共字段与约束，按判别字段的值选分支，普通枚举字段失效时只修正该字段，保留对象其余数据。
- 默认值生成与迁移会组合应用于同一属性或数组元素的多处声明。
- 子 schema 校验保留嵌套 `$id` 与 `$anchor` 的作用域，并正确定位名称中含字面量 `%` 序列的属性。
