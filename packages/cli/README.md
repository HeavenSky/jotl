# @jotl/cli

**English** · [简体中文](./zh/README.md)

Compile Jotl to JSON Schema and TypeScript, validate JSON data, and migrate legacy schemas from the terminal or CI.

`jotl` is the command line for [Jotl](../../README.md), a compact language that compiles to JSON Schema 2020-12. It is for teams that keep form or configuration schemas in a repository and need to build, check and validate them in scripts. Instead of chaining a schema generator, a TS generator and a validator, you run one tool that reads Jotl, JSON Schema and TS declarations, reports every problem as `file:line:column`, and exits with `0`, `1` or `2` so CI can act on it.

## See a failing check

A schema in Jotl and a data file that breaks it:

```jotl
Home: {
  title: string[maxLength: 20]
  count?: integer[minimum: 1]
}
```

```json
{ "title": "Welcome", "count": 0 }
```

`jotl validate` points at the offending value in the data file:

```console
$ jotl validate home.jotl home.json
home.json#/count JOTL4003 error: count is out of range: should be at least 1
  home.json:3:3 location in the data file
home.json: failed
```

The verdict goes to stdout, the diagnostic to stderr, and the exit code is `1`.

## Get TypeScript types in three steps

You need Node 22 or later.

1. Add the command line to your project:

    ```sh
    pnpm add -D @jotl/cli
    ```

2. Write a one-field schema:

    ```sh
    printf 'Home: {\n  title: string[maxLength: 20]\n}\n' > home.jotl
    ```

3. Compile it to TS declarations:

    ```sh
    pnpm exec jotl compile home.jotl --to ts
    ```

    The output starts with `// Generated by Jotl. Do not edit.` and declares `export interface Home` with `title: string`. Drop `--to ts` to get the JSON Schema instead.

## What you get

- **Move between Jotl, JSON Schema 2020-12 and TS declarations in any direction.** `compile` and `convert` write to stdout or `--out`, and `--typia-tags` emits typia type tags in TS output.
- Catch broken data and schemas in CI: `validate` locates each error in the data file, `check` reports schema problems without output, and `defaults` prints the default data a schema implies.
- Bring old schemas forward: `migrate-schema` upgrades draft-04 through 2019-09 schemas and OpenAPI 3.0 / 3.1 and Swagger 2.0 Schema Objects to 2020-12, and turns Fengdie schemas into Jotl.
- Parse the output with a script: one diagnostic per line, stable exit codes, `-` reads from stdin, and messages come in English or Chinese via `--lang` or `JOTL_LANG`.
- Use your project's own components: commands that compile Jotl pick up the nearest `jotl.config.json`, the same file the editor reads.

## Know the limits

`jotl` reads Jotl, JSON Schema and TS files and validates JSON data only. To edit Jotl with live checks and a preview, use the [VS Code extension](../vscode/README.md) or plug the [language server](../language-server/README.md) into your editor; to validate data inside an application, call [`@jotl/data`](../data/README.md) instead of spawning the command line.
