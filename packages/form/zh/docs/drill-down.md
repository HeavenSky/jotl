# 浏览嵌套数据

[English](../../docs/drill-down.md) · **简体中文**

本页说明 `JotlForm` 如何显示对象、数组和字典，以及如何把当前层同步到路由或关闭钻取。

## 每层一页

表单默认每层一页。当前层的标量字段直接编辑；复合字段（对象、数组、字典、有对象分支的联合、递归节点）显示为入口行，点击进入下一层。顶部面包屑由各层标签组成，点上一级即可退回。

```tsx
const [path, setPath] = useState('');
<JotlForm schema={schema} path={path} onPathChange={setPath} />;
```

- `path` 是当前页的数据路径（JSON Pointer），可同步到宿主路由。不传时表单自己维护当前页，初始为根 `""`；传入后受控，进入与退回只经 `onPathChange` 通知。
- `x-ui.widget: "inline"` 的对象在父页内展开。数组页与字典页中，标量元素直接编辑，复合元素为入口行。

## 入口行与面包屑显示什么

- 入口行显示标签、摘要与其下的错误数。
- 摘要取 `x-ui.summary` 指定的字段（写在数组、字典上时作用于元素）。不写时取第一个非空字符串字段；数组元素再没有时显示 `第 n 项`（英文界面为 `Item n`）。
- 面包屑中数组元素同样取摘要或序号，字典值取键名。

## 表单何时自动换页

下面两种换页都经 `onPathChange` 通知：

- 提交校验失败时，跳到第一个错误所在的层。
- 当前显示的数组元素或字典键被删除，或字典键被改名时，退回该数组或字典所在的层。`path` 指向不存在的数组元素时同样处理。

## 找到其他页上的错误

不在当前页的错误显示在页顶的表单级列表中，面包屑的上层还标出其下（且不在下一层）的错误数，点击该层后由入口行指明位置。点击表单级列表中的一条错误会切到它所在的页，再滚动到并聚焦该字段。不钻取时直接聚焦；字段被隐藏时聚焦最近的可见上层。

## 全部显示在一页

```tsx
<JotlForm schema={schema} drill={false} collapsible />
```

- `drill={false}` 时各层在同一页展开，不显示入口行与面包屑，并忽略 `path`。
- 再加 `collapsible` 时，对象（`inline` 除外）、数组、字典与含对象分支的联合各包在可折叠面板中。面板标题行显示标题（数组元素为 `第 n 项`）、摘要与错误数；第一层默认展开，更深的默认收起。`drill` 为 `true` 时忽略 `collapsible`。
